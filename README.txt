MONTHSARY WEBSITE — SOFT PINK COQUETTE EDITION

FILES
- index.html: all six sections and text
- style.css: colors, layout, flower illustration, responsive styling
- script.js: navigation, floating hearts, letter reveal, flower animation
- images/: add photo1.jpg, photo2.jpg, photo3.jpg
- music/: optional song file named our-song.mp3

SECTIONS
1. Home
2. About Us
3. About You
4. Memories (photos and optional song)
5. A Letter for Her
6. A Flower for You (animated digital flower)

ADD PHOTOS AND MUSIC
Upload your photos to images/ using the exact names photo1.jpg, photo2.jpg, photo3.jpg.
Optional: upload an audio file you have permission to share as music/our-song.mp3.
If you don't want to upload audio, you can remove the audio block from index.html.

EDIT YOUR WORDS
Open index.html in GitHub and use the pencil icon to edit the sample wording. Save with Commit changes.
You can also edit index.html in a Chromebook text editor before uploading.

PUBLISH WITH GITHUB PAGES
1. Sign in at https://github.com and create a repository named our-monthsary.
2. Upload index.html, style.css, script.js, and README.txt, then commit.
3. Create images/.gitkeep and music/.gitkeep using Add file > Create new file, and commit each.
4. Upload your photos into images/ and optional song into music/.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose main and /(root), then Save.
8. Wait a few minutes and open the URL shown in Settings > Pages. It typically looks like:
   https://YOUR-USERNAME.github.io/our-monthsary/

PRIVACY
GitHub Pages is a public-facing website. Do not upload private messages, identifying information, or pictures unless you're both comfortable with them being online. Check current GitHub plan/settings if you need a private repository; do not assume a public website is private.
